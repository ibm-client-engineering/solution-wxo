### Get your Google API Key

1. Log in with the Google account required for LLM authentication [here](https://aistudio.google.com/app/apikey)
2. Click "Create API Key"
3. Select "Generative Language Client"
4. Click "Create API Key in Existing Endpoint"
5. Save the generated API key
